TARTUF FINDER ALBANIA — v1.0

Aplikacion web për Android/iPhone/PC (PWA). Nuk është APK.

TESTIMI NË KOMPJUTER:
1. Hap terminalin në këtë dosje.
2. Ekzekuto: python -m http.server 8000
3. Hap http://localhost:8000

PËR TELEFONIN:
Publiko dosjen në një hosting HTTPS (p.sh. GitHub Pages / Netlify).
Hap URL-në në Chrome Android, pastaj menuja > Add to Home screen / Install app.
GPS kërkon HTTPS (ose localhost) dhe leje të përdoruesit.
Analiza funksionon offline pas ngarkimit fillestar. Harta OpenStreetMap kërkon internet.

KUJDES: Rezultati është indeks demonstrues i përshtatshmërisë, jo model AI apo parashikim i verifikuar i pranisë së tartufit.
